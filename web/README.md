# Web App (`apps/web`)

The `web` app is the React frontend for NBA Analytics Hub.  
It renders the analytics dashboard and consumes the backend API via shared libraries.

---

## Purpose

- Provide a single-page dashboard for upcoming NBA games.
- Visualize predictions and basic analytics.
- Demonstrate how the monorepo’s shared libraries (`ui`, `domain`, `data-access`, `types`) are used from a React app.

---

## Tech Stack

- **React** (Vite, TypeScript)
- **Nx** for project orchestration
- **Vitest** + **@testing-library/react** for unit/integration tests
- **MSW** for API mocking, in tests and in the browser
- Shared libraries:
  - `@nba-analytics-hub/ui` for layout and components
  - `@nba-analytics-hub/games` and `@nba-analytics-hub/prediction` for API clients, types, and pure helpers
  - `@nba-analytics-hub/platform` for shared helpers (dates, HTTP)

---

## Mock API (MSW)

The handlers live in `src/mocks/handlers`. Tests and the browser use the same ones.

- **Tests:** import `server` from `src/mocks/server`. Start it with `server.listen()` in `beforeAll`, and reset it with `server.resetHandlers()` after each test. Use `server.use(...)` to change one answer in a test.
- **Browser:** `npm run serve:web:mocks` runs the app with no API. The worker starts only when `VITE_USE_MOCKS=true`, and never in a production build.
- **Leaderboard:** the mock sorts, filters and pages made-up players the way the API does. Each season and season type gives the same rows every time.
- **Games and predictions:** the mock returns `mockGames` from `@nba-analytics-hub/games`. A game always gets the same prediction.
- `public/mockServiceWorker.js` is generated by `npx msw init web/public`. Do not edit it.

## Responsibilities

The web app is responsible for:

- Rendering the main dashboard layout using `AppShell` from `@nba-analytics-hub/ui`.
- Displaying a list of games for the selected date using shared types and components.
- Requesting predictions for games via `@nba-analytics-hub/prediction`.
- Showing prediction output (win probabilities, favored team) visually.

Back-end logic, data fetching implementation, and model integration live outside this app and are accessed only via shared libraries and the API.

## Development

From the repository root:

### Start the dev server

```sh
npx nx serve web
```

The app will start on the configured Vite dev port.

### Run tests

```sh
npx nx test web
```

Tests are written with Vitest and React Testing Library.

### Build

```sh
npx nx build web
```

Build artifacts are emitted by Vite into the app’s dist directory.
